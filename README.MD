About
=====

Library for probabilistic inference and simulation.

[![Documentation Status](https://readthedocs.org/projects/probability/badge/?version=latest)](https://probability.readthedocs.io/en/latest/?badge=latest)

Documentation
=============

Documentation is available at [probability.readthedocs.io](https://probability.readthedocs.io/).

Requirements
============

* numpy
* pandas
* scipy
* matplotlib
* numba (used for faster exact calculation of Beta-Binomial inequality)

Installation
============

    pip install probability
